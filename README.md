## 🚀 How to Host on GitHub Pages

### Option A: User Site (`https://<username>.github.io`)
1. Create a new repository named `hawkwheels.github.io` on GitHub.
2. In this directory, run:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Liquid Glass portfolio"
   git branch -M main
   git remote add origin https://github.com/hawkwheels/hawkwheels.github.io.git
   git push -u origin main
   ```
3. GitHub Pages will automatically publish the site at `https://hawkwheels.github.io/` within 1–2 minutes!

### Option B: Project Repository (e.g. `https://hawkwheels.github.io/portfolio/`)
1. Create a repository named `portfolio` on GitHub.
2. Push this codebase:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Liquid Glass portfolio"
   git branch -M main
   git remote add origin https://github.com/hawkwheels/portfolio.git
   git push -u origin main
   ```
3. In GitHub repo settings: **Settings** → **Pages** → under **Build and deployment**, select:
   - Source: **Deploy from a branch**
   - Branch: `main` / folder: `/(root)`
   - Click **Save**.
